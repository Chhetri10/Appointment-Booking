How to fix / activate your Firebase Database:

  1. Visit your Firebase Console (Project: myapp-c5fd7).
  2. In the left menu, navigate to Build > Realtime Database.
  3. If it shows "The database has been deactivated", click Reactivate database (or create the database instance in us-central1).
  4. In the Rules tab, ensure read and write permissions are enabled: 
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}

💡 Offline-First Resilience: While Firebase is deactivated or offline, your app will automatically run in local mode so you can sign up, log in, and book appointments without being blocked!
